# AI-sass-image-generation
<image src="./public/demo.png"><image/>


An AI-powered image generation platform built with OpenAI, featuring different image styles, generation history, user accounts, and subscription plans.

## Features

* AI image generation with multiple presets
* Premium landing page with 3D visuals and gradients
* Authentication using Clerk

  * Google
  * GitHub
  * Email and password
* Email verification
* Image generation history
* User dashboard with generation usage
* Subscription system

  * Free: 3 generations/month
  * Pro: $19/month — 75 generations
  * Studio: $29/month — 175 generations
* Smart plan upgrades where users only pay the price difference
* Monthly and yearly subscriptions
* Email notifications and payment receipts

### AI Presets

* Storybook
* Anime Cel
* Clay Render
* PixArt
* Voxel Block
* Marble Sculpture

## Tech Stack

* OpenAI
* Next.js
* Clerk
* PostgreSQL
* Drizzle ORM
* TanStack Query
* Tailwind CSS
* shadcn/ui
* Sentry
* Cline

## Deployment

The project is designed to be easy to deploy and can run using  free-tier services.
